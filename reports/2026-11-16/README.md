## 解释范围

固定帧门限验证能学习正确排列，正式训练结束验证训练流程；性能由以上独立测试计数决定。G-ECCT 或联合模型可能弱于传统译码器，不能将训练成功视作性能提升。

运行同时存在其他 GPU 任务，未做隔离延迟基准；此报告不宣称速度优势。X410 仅有模拟 IQ 离线接口验证，尚未进行射频实采。

原始核心源码对应 Git 标签 `frozen-20261116`；当前主分支的续跑修复不改变这些历史计数。
权重、原始 IQ、环境和本机日志不包含在 Git 中。报告/诊断生成代码以 `.py.txt` 归档，
保留原运行产物，不作为当前位置可直接运行的入口。
